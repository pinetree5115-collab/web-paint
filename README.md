# Web Paint App

이 프로젝트는 바닐라 JavaScript로 그림을 그릴 수 있는 웹 앱을 만드는 클론코딩 실습입니다.
원본: [바닐라 JS로 그림 앱 만들기
/https://nomadcoders.co/javascript-for-beginners-2/lobby]

## ✨ 주요 기능

- **자유로운 그리기:** 캔버스 위에서 마우스를 움직여 자유롭게 그림을 그릴 수 있습니다.
- **선 굵기 조절:** 슬라이더를 이용해 선의 굵기를 실시간으로 조절할 수 있습니다.
- **색상 조절:** 선의 색상을 실시간으로 변경할 수 있습니다.
